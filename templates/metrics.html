Evaluation Methodology

Hallucination rate — share of answers containing claims unsupported by retrieved context, judged against a labelled QA set (baseline = same model without RAG).

Faithfulness — sentence-level entailment of answer claims over the injected context block.

Precision@5 — fraction of FAISS top-5 chunks marked relevant by human annotators.

F1 (classification) — macro-averaged over Invoice / Contract / Report / Resume / Research Paper / Policy / Other.

ROUGE-L — LCS-based F1 against human-written reference summaries.

Latency — full request time: embed → FAISS search → Groq generation, measured at the API edge.
